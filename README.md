# Akademisyen Not ve İstatistik Yönetim Sistemi

Görsel Programlama dersi kapsamında C# Windows Forms kullanılarak geliştirilmiş; akademisyenlerin öğrenci notlarını kaydetmesine, güncellemesine ve sınıf bazlı istatistikleri görüntülemesine olanak tanıyan 3 formlu masaüstü uygulamasıdır.

## ✨ Temel Özellikler
* **Çok Formlu Yapı:** Giriş, not yönetimi ve istatistik ekranları arasında düzenli geçiş
* **Kalıcı Veri Depolama:** Öğrenci ve not kayıtlarının yerel metin dosyası (`ogrenciler.txt`) üzerinden okunup yazılması
* **İstatistiksel Analiz:** Sınıf ortalaması, en yüksek/en düşük not ve başarı durumu hesaplamaları

## 🛠️ Kullanılan Teknolojiler
* **Dil & Arayüz:** C# (.NET Framework / Windows Forms)
* **IDE:** Visual Studio
* **Veri Saklama:** Dosya Tabanlı Kalıcılık (`System.IO`)
